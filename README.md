# QQ-AI-Friend
# QQ AI 聊天机器人

一个基于本地 Ollama 的 QQ AI 聊天机器人，通过 NapCat WebSocket 连接 QQ，模拟一个大二女大学生的日常状态和情绪。

## 功能特性

### 🧠 核心对话
- 本地 Ollama 模型驱动
- 长期对话记忆（按天归档）
- Few-shot 示例引导，回复更自然
- 内心参考系统（时间、地点、心情、事件背景）

### 😊 情绪与状态系统
- **疲劳值**：随时间增加，随睡觉/休息降低
- **心情系统**：受事件、天气、季节、生理期影响
- **亲密度系统**：每个用户 0-100，影响回复语气和速度
- **体重系统**：每天波动，生理期水肿，体重焦虑
- **生理期系统**：每28天一次，期间情绪差、想吃甜的

### 📅 事件系统（199个事件）
- **日常事件**：13条，按时间段自动触发
- **随机事件**：145条，各种校园生活小插曲
- **稀有事件**：41条，低概率大事件
- **持续事件**：所有事件都有开始时间和结束时间
- **事件互斥组**：
  - 🛌 休息组：午觉、午休、泡热水澡（互斥）
  - 📚 学习组：上课、图书馆、赶ddl（互斥）
  - 🚶 出门组：逛武康路、外滩、操场（互斥）
- **事件叠加**：小事可和任何主事件同时进行
- **重要程度**：1=小事（叠加）、2=中等（打断小事）、3=大事（打断所有）

### 💰 生活模拟系统
- **生活费系统**：每月2500元，三餐/零食/夜宵自动花销
- **三餐系统**：食堂/外卖根据疲劳值决定，20+种上海特色食物
- **夜宵系统**：晚上9点后概率触发
- **消耗品系统**：14种物品，每天消耗
- **购物系统**：快用完了会心情不好，偶尔去超市购物
- **知识系统**：各科知识值每天增长，上课加得更多

### 🎓 校园生活
- **课程表**：自动读取当天课程，上课期间事件切换
- **节假日系统**：自动获取法定节假日API
- **寒暑假**：寒假1.15~3.1，暑假7.1~9.1
- **考试周**：期中/期末压力大、复习忙
- **实习系统**：暑假50%概率去实习
- **季节变化**：春夏秋冬不同心情和事件

### 💬 社交行为模拟
- **主动消息**：每隔1~4小时主动找你聊天
- **已读不回**：受疲劳/心情/亲密度/睡觉/忙碌影响
- **智能延迟回复**：已读不回后，根据原因自动延迟回复
  - 睡着了 → 30~90分钟后醒了回
  - 在忙/事件中 → 事件结束后回
  - 太累了 → 30~60分钟后缓过来
  - 心情差 → 20~40分钟后心情好点
  - 走神了 → 10~20分钟后看到了
  - 看手机时 → 提前回复
- **撤回消息**：5%概率撤回最后一条
- **已读不回解释**：下次主动消息会解释刚才为什么没回

### 🌤️ 天气联动
- 自动获取实时天气
- 雨天/晴天事件权重×3
- 雨天：泡奶茶、图书馆看书、踩水...
- 晴天：晒被子、骑车、操场躺...

### 📊 其他
- **认识天数**：记录第一次聊天日期
- **未来规划**：考研/找工作焦虑事件
- **社交媒体**：刷小红书/抖音/微博事件
- **熬夜系统**：动态概率，疲劳越高入睡越早
- **睡眠系统**：根据明天课表动态调整起床时间

## 快速开始

### 前置要求
1. 安装 [Ollama](https://ollama.com/)
2. 下载模型：`ollama pull 模型`
3. 安装 [NapCat](https://github.com/NapNeko/NapCatQQ) 并连接 QQ

### 配置
编辑 `data/config.json`：
```json
{
  "ws_url": "ws://127.0.0.1:3001/?access_token=password",
  "ollama_url": "http://127.0.0.1:11434/api/chat",
  "model_name": "模型",
  "master_qq": "你的QQ号",
  "default_city": "上海"
}
```

### 运行
```bash
python main.py
```

## 聊天命令

私聊时发送：
- `/状态` - 查看当前状态
- `/事件` - 列出所有事件互斥组
